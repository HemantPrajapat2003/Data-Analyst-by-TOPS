# Session 2 — Data & Databases

## What's included
- `data/trending_movies.json`: self-created JSON list used by the Python task.
- `python/print_movie_titles.py`: reads JSON and prints each movie title.
- `data/zomato_restaurants_sample.csv`: **synthetic practice data**, not real Zomato data.
- `sql/zomato_import_and_query.sql`: example MySQL table definition and a city-count query.
- `docs/task_answers.md`: answers and instructions for all five tasks.

## Run Task 2
Install Python if needed, then from this folder run:
`python python/print_movie_titles.py`

No extra Python packages are needed.
